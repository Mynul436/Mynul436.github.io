## Free hosting: GitHub Pages

1. Create a public repository named `YOUR-GITHUB-USERNAME.github.io`.
2. Upload `index.html` and `style.css`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Visit `https://YOUR-GITHUB-USERNAME.github.io/`.

Before publishing, replace the LinkedIn URL if needed and add real GitHub/demo links for projects you can show.

Do not add confidential source code, client data, credentials, API keys, or private company information.
